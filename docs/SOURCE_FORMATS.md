# Supported source formats

MCQ Exam Builder supports 27 source extensions across Word/Office, OpenDocument, spreadsheet, text, structured-data, HTML and selectable-text PDF workflows.

Core requirements are consistent across formats: each question must resolve to one question stem, two to six options, and one correct answer before generation. Ambiguous or unsupported structures are surfaced for review rather than silently repaired.

Scanned or graphical PDFs are not OCR'd. Complex Word drawings, linked images, merged question tables, formulas and malformed Office containers may be rejected with preparation guidance.
